# Política de segurança

Se você identificar uma vulnerabilidade, evite publicá-la com detalhes exploráveis em uma issue pública. Entre em contato pelo canal disponibilizado no [Linktree do desenvolvedor](https://linktr.ee/Jessechagasdev) e descreva o impacto, a versão afetada e passos mínimos para reproduzir, sem anexar cookies, credenciais ou dados pessoais.

Este projeto é mantido de forma independente e não possui prazo garantido de resposta. Não use a extensão para testar sistemas de terceiros sem autorização.
