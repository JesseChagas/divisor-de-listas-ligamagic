# Publicar o site com GitHub Pages

1. Envie este projeto para um repositório público no GitHub.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/docs`, depois salve.
5. Após a publicação, o endereço normalmente será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
6. Edite `docs/index.html` para adicionar o link real do repositório aos botões de download e código-fonte quando o repositório existir.

A página inclui duas capturas de tela fornecidas pelo desenvolvedor. Não afirma afiliação oficial com a LigaMagic.
