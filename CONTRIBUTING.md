# Como contribuir

Obrigado por considerar contribuir com o Divisor de Listas.

## Antes de começar

- Procure issues e pull requests existentes para evitar trabalho duplicado.
- Para mudanças grandes, abra uma issue para discutir a proposta antes de implementar.
- Mantenha a interface e a documentação em português do Brasil, salvo quando houver motivo para outro idioma.

## Pull requests

1. Crie uma branch com um nome descritivo.
2. Faça mudanças pequenas e focadas.
3. Execute `node --check` nos arquivos JavaScript alterados e os testes relevantes em `tests/`.
4. Teste em um perfil de navegador separado, sem carrinhos ou compras reais.
5. Atualize README/tutorial se mudar o comportamento visível.
6. Na descrição, explique o problema, a solução e como foi testada; identifique limitações conhecidas.

## Segurança e privacidade

Nunca inclua cookies, tokens, credenciais, dados pessoais ou dumps de sessão em commits, issues ou logs compartilhados. Não implemente mecanismos para contornar bloqueios, desafios ou limites de acesso de sites. Reporte vulnerabilidades em particular conforme `SECURITY.md`.

Ao contribuir, você concorda que sua contribuição será distribuída sob a licença do projeto (MIT), salvo acordo escrito em contrário.
